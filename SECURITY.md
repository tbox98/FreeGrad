# Security Policy

If you discover a security vulnerability, **please do not open a public issue**.

## Reporting a Vulnerability
Email **security@kebula.it** with the subject line: `[freegrad] Security report` and include:
- A description of the issue and potential impact
- Steps to reproduce (proof of concept), if available
- Your environment details (OS, Python, freegrad version)
- Any suggested mitigations

We will acknowledge receipt and aim to respond within 72 hours. Once confirmed, we will coordinate a disclosure timeline and publish a patch release.

## Supported Versions
We generally support the latest minor release line. Security fixes will be backported when feasible.
